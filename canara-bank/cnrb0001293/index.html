How the code CNRB0001293 is built

CNRB is the bank part: the letters of Canara Bank. The fifth character is always the digit 0. 001293 is the part that names this branch.

The MICR code 562015991 is the number printed along the bottom of this branch's cheques. 562 is the city (the same three digits that begin the PIN code 562104), 015 is the bank and 991 is the branch.
