How the code CNRB0001534 is built

CNRB is the bank part: the letters of Canara Bank. The fifth character is always the digit 0. 001534 is the part that names this branch.

The MICR code 571015538 is the number printed along the bottom of this branch's cheques. 571 is the city (the same three digits that begin the PIN code 571213), 015 is the bank and 538 is the branch.
